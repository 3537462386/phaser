# 太空射击 — 肉鸽玩法优化 GDD

> 版本: 1.0 | 日期: 2026-05-28 | 状态: 已实现核心系统

---

## 设计支柱

| 支柱 | 玩家体验目标 |
|------|-------------|
| 构建多样性 | 每局体验不同，遗物+武器+诅咒组合产生差异化 |
| 风险收益 | 诅咒/赌博/牺牲机制让玩家主动承担风险 |
| 局程节奏 | Boss 战提供高潮，事件提供惊喜，商店提供规划 |
| 协同快感 | 遗物与武器联动产生 1+1>2 的效果 |

## 新增系统概览

| 系统 | 文件 | 核心功能 |
|------|------|----------|
| 被动遗物 | `PassiveItemData.js` + `PassiveItemManager.js` | 14种遗物，4类(攻击/防御/功能/诅咒)，可叠加 |
| Boss战 | `BossData.js` + `BossManager.js` | 3种Boss，每5轮出现，阶段2变化，稀有掉落 |

| 武器进化 | `WeaponData.js` → `WEAPON_EVOLUTION` | 6种终极形态，需催化剂遗物+满级 |
| 扩展升级 | `UpgradeManager.js` (重写) | 遗物选项+进化选项+加权随机+协同优先 |

## 核心循环 (优化后)

```
战斗层(0-30秒) → 移动躲避 → 自动射击 → 击杀敌人 → 掉落拾取
     ↓ 经验升级
构建层(5-30分钟) → 选遗物/升级武器/武器进化/诅咒抉择
     ↓ 轮次完成
节奏层(小时) → 普通轮(累积) → Boss轮(高潮) → 事件(惊喜) → 商店(规划)
```

### 协同效应设计

协同 = 遗物的 synergy 字段列出与哪些武器有主题联动：
- **放大镜 + 机炮** → 机炮双排齐射 + 伤害提升 = 高频高伤输出
- **爆裂核心 + 散弹** → 散弹多方向击杀 → 更频繁触发爆炸
- **穿透透镜 + 追踪弹** → 追踪弹穿透后继续追击下一个目标
- **护盾碎片 + 护盾球** → 防御体系，近身/远程双重保护
- **血之契约 + 激光** → 激光高频伤害大幅提升，血量低但DPS极高

## Boss 系统

### Boss 出场顺序

| 轮次 | Boss | HP | 攻击模式 |
|------|------|----|----------|
| 第5轮 | 虫群女王 | 40 | 生成小兵 + 冲撞 |
| 第10轮 | 晶体堡垒 | 60 | 环形弹幕 + 生成重型兵 |
| 第15轮+ | 虚空收割者 | 80 | 环形弹幕 + 冲撞 + 生成快速兵 |

### Boss 阶段变化

所有 Boss 在 HP 低于阈值时进入阶段2：
- 速度提升
- 攻击频率加快(间隔x0.6)
- 闪烁提示

### Boss 掉落

- 金币: 30/50/80 (随 Boss 等级递增)
- 遗物: 随机 Tier 2 遗物一件

## 轮间事件系统

### 事件触发规则

- 第1轮不触发
- Boss轮不触发
- 其他轮次 50% 概率触发
- 事件在商店之前触发

### 事件清单

| 事件 | 类别 | 选项 |
|------|------|------|
| 恶魔交易 | 诅咒 | 献2HP上限换40金 / 拒绝 |
| 星际赌场 | 赌博 | 投15金(50%翻倍) / 投30金(33%三倍) / 离开 |
| 神秘宝箱 | 神秘 | 打开(60%遗物/40%受1伤) / 无视 |
| 流浪商人 | 交易 | 买遗物(25金) / 卖HP换金 / 离开 |
| 能量涌动 | 神秘 | 吸收(移速+10%受伤+1) / 排斥(冷却-10%) |
| 古代遗迹 | 诅咒 | 读符文(T2遗物但HP-2) / 离开 |
